**The application interface is currently in Turkish.** English documentation does not add an English interface or a language switch to the app. Existing installations and stored records are unaffected by documentation updates.

When updating a document, keep the corresponding translation consistent. Interface labels in the English usage guide retain the current Turkish labels so users can find the correct controls.
