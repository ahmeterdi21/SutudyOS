# StudyOS v0.5.0

## Türkçe

- Derslerim, ders rengine göre desenlenen cam klasörlerle yenilendi. Klasörden bekleyen görev veya bağlı PDF açılabilir; odaklanma ve silme onayı korunur.
- Asistan’a genel amaçlı metin sohbeti eklendi. Konu anlatımı, metin düzenleme, fikir geliştirme ve genel sorular mevcut ChatGPT/Gemini bağlantısıyla kullanılabilir. Çalışma planı ayrı bir seçenek olarak korunur.
- Animasyonlu mesaj kutusu, soru önerileri, mesaj kopyalama ve yeni sohbet eklendi.
- Ayarlar alt menüden sağ üste taşındı.

Sohbet geçmişi yalnız açık oturumda tutulur. Yakın geçmiş seçilen hizmete paylaşım onayıyla gönderilir; dersler ve PDF’ler otomatik paylaşılmaz. Dosya yükleme ve internet araması bu sohbet sürümünde yoktur. Sağlayıcı kotaları ve hesap uygunluğu geçerlidir.

## English

- Glass lesson folders with color-based procedural artwork and real task/PDF shortcuts.
- General-purpose text chat alongside the existing study-plan assistant, using the selected ChatGPT or Gemini connection.
- Animated composer, prompt suggestions, message copying and new-chat action.
- Settings moved out of bottom navigation into the top-right corner.

Chat history is session-only. Recent messages are sent to the chosen provider with explicit consent; subjects and PDFs are not automatically shared. File upload and web search are not included. Account eligibility and quotas apply.

Validation: frontend and Windows native builds, 38 application tests, 7 Rust tests and 3 release-configuration tests passed. Live general-chat generation still requires user verification.
