# StudyOS v0.4.0

## Türkçe

Modern pencere görünümü, spotlight kartlar ve isteğe bağlı çalışma planı asistanı.

- Mavi Windows başlık çubuğu yerine uygulamayla bütünleşen pencere düğmeleri.
- Görev çubuğunu koruyan büyütülmüş açılış ve tutarlı yeni logo.
- Kartlarda hafif 3D hareket, fareyi takip eden ışık ve azaltılmış hareket desteği.
- ChatGPT hesabı veya kişisel Gemini anahtarıyla çalışma planı önerileri.
- Önerileri inceleme, düzenleme ve seçerek planlayıcıya kaydetme.
- Bağlantı bilgilerinin Windows ile şifrelenmesi.

Asistan önizleme aşamasındadır; canlı hesap bağlantısı ve plan üretimi henüz kullanıcı tarafından doğrulanmadı. ChatGPT uygunluğu ve kotaları geçerlidir. Gemini ücretsiz kotası projeye bağlıdır; faturalandırması açık projeler ücret doğurabilir. Temel özellikler hesap gerektirmez.

## English

Modern window controls, spotlight cards and an optional study-plan assistant.

- Integrated window controls, maximized startup and a consistent geometric logo.
- Subtle 3D card tilt and pointer spotlight, respecting reduced-motion preferences.
- ChatGPT account connection or a personal Gemini API key alternative.
- Editable suggestions with explicit confirmation before adding tasks to Planner.
- Windows-encrypted credentials.

The assistant is a preview. Live authorization and generation remain unverified by the user. Account eligibility, quotas and regional availability apply; billing-enabled Gemini projects may incur charges. Core features need no account.

Validation: frontend and Windows native builds, 33 application tests, 6 Rust tests and 3 release-configuration tests passed.
